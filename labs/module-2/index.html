Labs — Module 2: JavaScript

Ten hands-on exercises. This is code written to learn from, not a product — the product is ShopLite, now rendered by JavaScript.

Run these over a server, not from the file system. Lab 1.4 uses <script type="module"> and lab 3.2 calls a real API; both are blocked on file://. From the repository root: npx serve, then open http://localhost:3000/labs/module-2/.

Day 1 — Modern JavaScript (ES6+)

  1. Array methods

    map / filter / reduce / sort / find, and the same job written as a for loop and as a chain.

  2. Destructuring, spread & rest

    Renaming, defaults, nesting, safe copies — and the one-level-deep catch that spread does not solve.

  3. this & arrow functions

    One object, two methods, four ways of calling them. Then the setTimeout bug and its four fixes.

  4. ES modules

    Four files, export / import, default vs named. Needs a server.

Day 2 — DOM, events & dynamic rendering

  1. Render from data

    productCardHTML(p) plus list.map(...).join('') — one write to the DOM, no hand-written cards.

  2. Event delegation

    Per-button listeners on the left, one container listener on the right. Add a row and see which side still works.

  3. Real-time search

    Filtering on every input event, with a highlighted match and a proper empty state.

Day 3 — Async, Fetch & localStorage

  1. Promises & async/await

    The three states, then/catch next to await, sequential vs Promise.all, and the event loop.

  2. Fetch & error states

    Why fetch does not throw on 404, and the loading / data / error screens every request needs.

  3. localStorage

    A cart that survives a reload — including a button that corrupts the stored JSON so you can watch it recover.
