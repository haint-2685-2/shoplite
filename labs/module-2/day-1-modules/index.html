ES modules: export / import

Four files instead of one: data.js holds the products, format.js formats money, cart-math.js does the arithmetic, and main.js pulls them together. Loaded with <script type="module">.

This lab needs a server. Modules are fetched over HTTP, so opening the file directly (file://) fails with a CORS error. Run npx serve from the repository root and open it over http://localhost:3000.
