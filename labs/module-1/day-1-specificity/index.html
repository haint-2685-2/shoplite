Lab 1.3 — Which rule wins?

The fastest way to learn this: guess first, then look. Read the six rules in <style>, predict the text color of the "Target" row, and only then open the page.

  1. Count specificity in three columns: id – class/attr/pseudo-class – element.
  2. A left column outweighs every column to its right: 1-0-0 always beats 0-9-9.
  3. On a tie, the rule written later in the file wins.
  • Plain row (matches li only)
  • Matches li + .item + li.item
  • Adds [data-state="active"]
  • Target — matches all six rules
  • Row carrying !important

Answer: the "Target" row is red, because #target scores 1-0-0 — higher than any class or element rule above it, li.item:nth-child(4) (0-2-1) included. The last row is green because !important sits outside the specificity rules entirely.
