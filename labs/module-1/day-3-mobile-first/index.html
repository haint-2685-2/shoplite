A heading using clamp()

Both the font size and the padding of this box use clamp() — they scale continuously with the viewport instead of jumping at a breakpoint.

When to use which: a simple grid → auto-fill. When the structure itself has to change (one column becoming two with a sidebar, hiding or showing a block) → that is what a media query is for. Font sizes and spacing → clamp().
