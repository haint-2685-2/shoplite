Lab 1.2 — The box model in DevTools

The three rows below share width: 200px, padding: 24px and border: 6px. Open DevTools → Computed tab, click each card and read the Box model diagram to compare real widths.

1. box-sizing: content-box (the CSS default)

Real width = 200 + 24·2 + 6·2 = 260px. This is the root of every "why is my layout overflowing?" bug.
