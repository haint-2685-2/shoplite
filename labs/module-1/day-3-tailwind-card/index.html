The point: Tailwind is not a new way to do layout — it is a short name for exactly the CSS properties you just learned. The sm: / lg: prefixes are media queries, and hover: / focus: are pseudo-classes. Once the underlying CSS is solid, Tailwind is just a change of syntax.
