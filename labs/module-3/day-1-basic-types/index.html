Basic types, tuples, enums & inference

string, number, boolean, null, undefined, arrays, tuples and an enum — each assigned a wrong value on purpose. Then the same code with the redundant annotations removed, because TypeScript infers them.

Rule of thumb for annotations: write the type on function parameters, on return values of exported functions, and on variables that are declared before they get a value. Everywhere else, hover and let inference do it.
