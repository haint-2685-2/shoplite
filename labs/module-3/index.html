Labs — Module 3: TypeScript

Nine exercises. This folder is itself a Vite + TypeScript project — lab 1.1 is how it was made. The product is ShopLite v3 in v3-ts/, which has its own dev server.

Run: cd labs/module-3, npm install, npm run dev, then open http://localhost:5173/.
Every deliberate mistake is marked // @ts-expect-error, so npm run typecheck passes — and fails the moment one of them stops being an error. npm run check:errors also checks that each quoted message is word for word what the compiler prints.

Day 1 — TypeScript foundations + Vite

  1. Vite + TypeScript setup

    npm create vite, the project layout, tsconfig.json line by line — and the JavaScript the browser actually receives.

  2. Basic types & inference

    Primitives, arrays, tuples, enum vs as const, wrong assignments on purpose, and the annotations inference makes redundant.

  3. interface vs type

    Product, extends, ?, readonly, declaration merging — and what only type can express.

  4. Union types & narrowing

    type Status = 'idle' | 'loading' | 'error', a switch that narrows, and the never check that catches a missing branch.

  5. Typing functions & callbacks

    Parameters, returns, optional and rest parameters, function types, and callbacks whose types come from the signature.

Day 2 — Generics, async types & strict mode

  1. Generics

    identity<T>, getFirst<T> next to its any twin, constraints, keyof, and generic types you already use.

  2. Typing fetch & async

    getJSON<T>(): Promise<T>, getProducts(): Promise<Product[]>, failures folded into FetchState<T>.

  3. any vs unknown

    Paste JSON, watch the any version crash and the type-guarded unknown version explain why it refused.

  4. strict mode, flag by flag

    querySelector and getItem returning null, implicit any, catch as unknown — and why ! is not a fix.
